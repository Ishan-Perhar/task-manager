# Task Manager

A full-stack task management application built with:

- React
- TypeScript
- FastAPI
- PostgreSQL
- Docker

## Features

- User authentication
- Task creation/editing/deletion
- Task priorities
- Due dates
- Real-time updates
- Responsive UI

## Tech Stack

### Frontend
- React
- Vite
- TailwindCSS
- TypeScript

### Backend
- FastAPI
- SQLAlchemy
- PostgreSQL

### Infrastructure
- Docker
- Docker Compose
